### 权威缺口核验结论(本轮数据驱动盘点)
代码引用的资产**几乎全部已存在**:13 丹药图标✓、11 物品图标✓、24(现25)灵草+种子✓、7 NPC 精灵✓、3 守田兽✓、设施/地点/瓦片✓、3 结局 CG✓。**本轮前唯一真缺口 = 绝灵苔 2 图标**,现已补齐。其余"下一批美术需求"(更多 NPC/守田兽变体/图标覆盖率)是**未被代码引用的占位扩充**,非运行缺口。

### 决策:音频保持程序化,**不动 AI**(研究结论)
- 程序化 Web Audio(11 SFX + calm/tense BGM)是复古/修仙风 SFX 的最优解:零体积、零版权、可实时调参、chiptune 天然契合。
- **法律硬伤**:美国完全 AI 生成内容**不可版权**,对作品集/商业发布是硬风险;程序化音频项目 100% 拥有版权。
- 结论:SFX/BGM 维持程序化;未来若要"招牌主题曲",选 ElevenLabs Music(授权数据训练,法律最干净)做 1-3 首,其余程序化。**本轮零音频 API 支出。**

### 决策:管线升级建议(记录,**本轮不执行**)
调研(2026)强推荐把单步 `LANCZOS 1024→32` 换成 `网格对齐 → 分级 dominant-vote(256→64→32)→ OKLAB 去 AA → morph/jaggy 清理 → Lab 16色`,参考开源 [unfake.py](https://github.com/painebenjamin/unfake.py)/[pixfix](https://github.com/lovelaced/pixfix)。**未执行理由**:升级需重生现有 24 张灵草图标才一致=烧 token,且当前 8 色/ΔE=0 质量已过线;留作后续整批升级时统一应用。本轮 voidmoss 沿用既有 quantize 以与 24 同类视觉一致。

### 决策:未引用的未来美术(本轮不生成)
更多 NPC/守田兽/设施的占位美术属既有"下一批需求"台账项,代码尚未引用——**本轮不生成**(生成未被消费的资产=浪费付费 token)。待对应 sim 内容实装时,按本轮管线(edits 精修+5 闸门)增量补齐。

### 省 token 工程实践(已落地,供后续复用)
- 图标用 `quality:low`/默认(差 15×);body 绝不带 `size`/`n`(中转站 500);`/images/edits` 用程序化小底图锁几何(最省最一致)。
- 仅重试 `408/429(rate)/5xx`;`400/401/403` 立即终止不烧 credit;指数退避+jitter,超时 180s。
- `response_format=b64_json`(本地落盘);透明背景失败则下游角点洪水去背景(本轮 voidmoss 即此路径)。
- 密钥只走 `CG_API_KEY` 环境变量,**绝不入库**(CONTRIBUTING 红线)。

- `设施加工链` 的“忙碌中 / 已完成待收取”状态现也并入统一语义：`facilityStatusToastPresentation` 会继续保留 `facility.*`。原因是这类提示表达的仍是“这台设备此刻处于什么阶段”，玩家尚未真正拿到产物，因此仍应先读懂设备线程，而不是提前切到物品结果图标。
- `设施加工链` 的“启动失败”状态现也并入统一语义：`facilityFailureToastPresentation` 会继续保留 `facility.*`。原因是晾晒/封藏/熔炼失败时，玩家卡住的仍是设备线程本身，而不是某个已经到手或已经产出的物品结果；因此不再让这类高频失败态散落成无资产的裸字符串。

### AI 资产多重审核闸门（用户指令：AI 可用，须过审核）
任何 AI 生成资产入库前须**全部通过**以下阶段（`tools/review-ai-art.py` + 视觉判定）：
1. **fmt** — PNG 合法 + 尺寸符合类（sprite 精确 32×32；cg 大尺寸）。
2. **palette** — Lab ΔE 贴合 16 色调色板（sprite 量化后 mean ΔE≈0；cg 仅记录）。
3. **content** — 不透明率/唯一色数/单色洪泛检测，剔除废生成。
4. **vision** — 视觉语义审核（主体正确、无 AI 伪影、32px 下可读）；本环境用 `analyze_image`（zai MCP 401 不可用）。
5. **provenance** — `license=AI-Generated` + `source`（模型/端点/motif）+ `checksum` 由 manifest schema 强制。
- 前沿量化管线（调研落地）：去背景 → 预乘 alpha → 高斯 σ0.8 → **LANCZOS** 降采样 → 取消预乘 → alpha 二值化 → **Lab 最近邻**贴 16 色（**不抖动**）→ 中值去噪 → 连通域去孤立点。

### 3. BGM 质量升级（可选，非阻塞）

**绝灵苔美术简报（务必读）**：baseProperty 全 0（"空"——不吸灵气、反隔灵），程序化生成器默认取首元素会偏空/灰。**这正是主题所需**：绝灵苔是主角空灵根的镜像("空亦有空之用")、绝缘阵核心材料。视觉锚点=**苍白、近无色、灰白苔藓质感、极低饱和**（呼应 docs/03 §6.1 与 §9.2 意象"绝灵苔=空"），刻意区别于同为寒白的虚衾蕈（voidmantle，有极寒霜蓝）。避免误画成有灵光的草。
