# 04 · UX / 界面 / 控制 / 游戏流程 (Screens, HUD, Controls, Flow)

> 把三大机制与系统（见 05–09）映射到玩家看到的**画面**、读到的**信息**、做出的**操作**。本文档为纯设计规格，不含实现代码。
> 关联：交互实现见 `10-technical-architecture.md`（输入层/模块）、美术视听基调见 `13-asset-art-audio.md`、数值见 `14-...md`、世界观文案锚点见 `03-world-and-lore.md`。

---

## 1. UX 设计哲学

1. **双模信息架构**：90% 时间是"治愈向慢节奏"，UI 安静、留白、信息克制；10% 是"天劫急迫"，HUD 变高对比、倒计时与雷预警占据视觉中心。**同一套 HUD，两套强度**，靠动效与色调切换，避免玩家在天劫期还要翻菜单。
2. **脆弱感外显**：凡人的脆弱（设计支柱 1）要在界面被"感知"——HP 条短而显眼、丹毒(PillPoison)条用毒色逼近满即视觉警告、体魄进度缓慢。让"快死了"成为持续的低压焦虑，而非偶发事件。
3. **信息分层**：核心生存状态（HP/丹毒/修为/灵气/时间）常驻；战术信息（阵法覆盖、雷预警、丹药快捷栏）仅天劫期叠加；细节（灵草属性、丹方）按需呼出（悬停/点开）。避免一次性信息过载。
4. **直接操作优先**：种田=走到地块按键；炼丹=拖料入炉+控火；布阵=把灵草种到对应位置即生效。减少抽象菜单，让"动作"与"结果"空间相邻（种田即布阵，见 08/05）。
5. **可学习、可回溯**：所有随机结果（炸炉、被劈、天象）都给"为什么"的可视化线索（药性平衡条溢出、雷落点预警、事件播报），让失败可学习。

## 2. 游戏流程状态机 (Game Flow FSM)

```
                 ┌───────────────┐
                 │  Title(标题)   │
                 └──────┬────────┘
            新游戏 / 继续存档 │
                 ┌──────▼────────┐
                 │ 序章过场 Cutscene│ ──(完成)──► 农庄主场景 FarmView
                 └───────────────┘                        │
                                                          │ ├─► 丹炉 AlchemyView
                                                          │ ├─► 储物戒/背包 InventoryView
                                                          │ ├─► 功法/突破面板 CultivationPanel
                                                          │ ├─► 地图/外出 MapView(舔包/挖脉)
                                                          │ └─► 暂停/菜单 PauseMenu
                       主动引劫 / 天道催讨倒计时归零            │
            ┌────────────────────────────────────────────┘
            ▼
     天劫承雷模式 TribulationMode ◄──(期间禁用种田/炼丹/外出)
            │  存活至雷劫结束
            ▼
     天劫结算 Aftermath(淬体收益/损失/突破判定)
            │
            ├─► 突破成功 → 回 FarmView(下一阶段)
            ├─► 失败(走火入魔/重伤) → 回 FarmView(惩罚) 或 Game Over
            └─► 终极紫雷劫通过 → 飞升结局 Ending(通关)
```

**状态切换的硬约束**：
- 进入 `TribulationMode` 时，**冻结**种田/炼丹/外出子场景（避免玩家在天雷下翻菜单致死）；仅允许：移动、服丹、（若设计允许）紧急布阵。
- 任何时刻可 `PauseMenu`（暂停=时间停止），但天劫期暂停**仅限设置/退出**，不允许"暂停偷操作"（防止破坏紧张感与平衡）。

## 3. 画面清单 (Screen Inventory)

| 画面 | 目的 | 主要元素 | 进入 / 退出 |
|------|------|----------|-------------|
| `TitleScreen` | 入口、新游戏/继续/设置 | 标题、菜单、版本 | 启动 → 选择 |
| `LoadScreen` | 选存档 | 存档列表(章节/日期/体魄阶段) | 继续 → FarmView |
| `PrologueCutscene` | 序章叙事+教程 | 旁白、可跳过、实操提示 | 新游戏 → FarmView |
| `FarmView`(主场景) | 种田/日常/布阵的核心舞台 | 瓦片农田、居所、玩家、常驻HUD、倒计时 | 默认驻留 |
| `AlchemyView`(丹炉) | 炼丹核心交互 | 槽位、火候控、药性平衡条、丹方提示 | 走近丹炉/快捷键 → Esc 返回 |
| `InventoryView`(储物戒) | 物品/种子/丹药/材料管理 | 格子、筛选、详情、丢弃/使用 | 快捷键 → 关闭 |
| `CultivationPanel`(功法) | 查看《偷天换劫诀》阶段/经脉/体魄进度 | 阶段树、经脉图、体魄进度、引劫条件 | 快捷键 → 关闭 |
| `MapView`(外出) | 灾年挖脉/战场舔包/偶发交易 | 山谷外围节点、风险提示 | 触发事件 → 完成/返回 |
| `EventOverlay`(天象播报) | 天象奇遇的告知与因果链展示 | 标题、类型标签、效果、应对提示 | 自动触发 → 确认/持续 |
| `TribulationHUD`(天劫承雷) | 天劫期战术信息叠加 | 雷预警、阵法高亮、HP/丹药快捷栏、控血提示 | 倒计时归零 → 结束 |
| `AftermathScreen`(天劫结算) | 收益/损失/突破判定反馈 | 淬体Buff、损失清单、突破成败 | 雷劫结束 → 继续 |
| `PauseMenu` | 设置/存档/退出 | 继续、设置、存档、退出 | Esc → 返回 |
| `SettingsScreen` | 音量/键位/可访问性/语言 | 滑条、开关、键位绑定 | 菜单 → 返回 |
| `EndingScreen` | 飞升/各结局/GameOver | 结局演出、统计、重玩/返回标题 | 触发结局 → 标题 |

## 4. 常驻 HUD（FarmView 默认）

布局（自上而下、自左而右，示意）：

```
┌─────────────────────────────────────────────────────────────┐
│  [⚡天劫倒计时 12:34  ▓▓▓▓▓░░░]   <日 N · 季 · 年>  [灵气●●] │  ← 顶部：时间/灵气/倒计时
│                                                             │
│                                                             │
│                     ( 瓦 棋 农 田 视 野 )                    │
│                                                             │
│                                                             │
│ [快捷丹药栏: 1承雷丹 2生骨丹 3净毒丹]                        │  ← 底部左：快捷栏
│ [❤HP ▓▓▓░] [☠丹毒 ▓░░░] [体魄(阶段II) ▓▓▓▓░░] [☰菜单]     │  ← 底部右：核心状态
└─────────────────────────────────────────────────────────────┘
```

**元素说明**：
- **天劫倒计时 (TribulationTimer)**：屏幕**正上方居中**。随时间推移视觉警示递进（绿→黄→红+脉冲+低频鼓点）。倒计时进度条与剩余时间双显。这是本游戏最核心的"压力源"，必须永远在视野内。
- **HP 条**：短而显眼；低于阈值（如 30%）边缘红光脉冲。
- **丹毒条**：毒色（紫/黑绿）；逼近满（如 80%）整屏边缘 vignette 警告 + 心跳音效；满即死。
- **体魄进度**：当前阶段《偷天换劫诀》淬体进度填充；满后显示"可主动引劫"，若天道注视/大限压力过高则转为"天道催讨"预警。
- **灵气指示**：当前地块/区域灵气浓度（影响生长与炼丹）。
- **快捷丹药栏**：数字键 1–N 快速服用（天劫期救命关键）。
- **时间/日期/季节**：右上角；季节图标暗示当前对灵草/天象的影响。

## 5. 天劫承雷 HUD（TribulationMode 叠加）

进入天劫模式时，常驻 HUD 之上叠加战术层：

- **雷预警标记**：每个将落雷的瓦片提前 1.5–3s 出现地面警示圈（颜色=雷类型，大小=威力），给玩家反应/走位/服丹时间。预警时长见 `05-mechanic-tribulation.md`【可调参数】。
- **阵法高亮**：已布设的引雷阵/绝缘阵范围半透明高亮（金=引雷、青=绝缘），让"种田即布阵"的成果在天劫期一目了然。
- **控血提示**：当 HP 处于"淬体收益甜区"（差点死但没死，见 05/14）时，给出克制的高亮提示（鼓励冒险）。
- **天劫剩余**：本场雷劫剩余雷数/倒计时。
- **禁用提示**：种田/炼丹/外出图标置灰，明示"天劫期不可用"。

**视觉/音频切换**：BGM 切紧张层（见 13-...md），屏幕轻微去饱和、雷光闪白（限频，见 §8 可访问性）、镜头随重雷微震。

## 6. 丹炉界面 UX（核心交互，对应 06-mechanic-alchemy.md）

参考 Potion Craft 的**空间化炼丹隐喻**：把"药性"可视化为炉内一个可被材料"推动"、被火候"锁定"的状态点。

```
┌─ 丹炉 AlchemyView ─────────────────────────────────────┐
│  残缺丹谱(当前推测) : [?]承雷丹  解锁度 60%            │
│                                                       │
│   投料槽位 Slots:  [槽1灵草] [槽2] [槽3] [辅料]        │
│                                                       │
│   药性平衡条 PropertyBar:                             │
│     寒 ◄════●════════════════════════════════════► 热  │
│        (当前药性和 = +12 温偏热  | 安全区 | 冲突区⚠)    │
│                                                       │
│   火候 Heat:  [══════●══════] 理想区间(此丹: 中火)     │
│              (低火 ── 中火 ── 武火，随时间漂移，需控)  │
│                                                       │
│   [出丹]  [弃炉]   ⚠冲突度 75% → 接近炸炉!            │
└───────────────────────────────────────────────────────┘
```

**交互**：
- **投料**：从储物戒拖拽灵草到槽位（或点击）；顺序影响结果（非线性，见 06）。
- **药性平衡条**：实时显示炉内 Σ药性向量（寒热温平映射为数轴，见 14）。进入"冲突区"→ 炸炉预警（震动+红条+滋滋声）。
- **火候控制**：火候随时间自然漂移，玩家用风箱/扇火调节（鼠标按住/滑条）；不同丹方有"理想火候区间"，偏离则降品质或炸炉。
- **残缺丹谱**：显示当前推测的目标丹药与解锁度，鼓励实验补全。
- **出丹/弃炉**：时机由玩家判断；过早=废丹，过晚=可能炸炉。

**关键 UX 原则**：药性平衡条与火候是**两个正交的压力源**，玩家同时管理 → 形成专注的"解谜操作"节奏，区别于种田的松散。

## 8. 信息架构、可读性与可访问性 (Accessibility)

- **药性编码不依赖单一通道**：寒=蓝、热=红、温=橙、平=绿（颜色）**+** 形状/符号（寒=向下三角、热=向上三角、温=圆、平=方）——色盲安全。
- **雷光闪烁限频**：天雷闪白 ≤ 3Hz（防光敏性癫痫），并提供"关闭强闪"开关；强雷用震屏+音效补偿视觉削弱。
- **文本可读性**：最小字号、高对比、描边；关键数字（HP/倒计时）大号加粗。支持文本缩放。
- **字幕与提示**：事件播报、丹方提示均可文字化；音效有可选视觉提示（如炸炉前的"⚠"）。
- **色盲模式**：提供多套调色板（含完全不依赖药性色的符号模式）。
- **暂停自由**：除天劫期限制偷操作外，日常随时暂停。
- **难度与辅助选项**：可调节天劫预警时长、炸炉宽容度、丹毒积累速率（标为"凡人难度/修罗难度"，不影响核心成就但记录）——既保挣扎感又给可及性出口。

## 9. 新手引导 (Onboarding)

- **序章即教程**：用凡间作物教翻地/播种/浇水/收获/时间流逝，无灵气无天劫，建立基础操作肌肉记忆与"种田很慢很治愈"的基调。
- **第一幕渐进解锁**：储物戒开启 → 解锁灵草（教"灵气生长"）→ 残缺丹谱（教"炼丹+药性"）→ 第一次小天劫（教"倒计时+雷预警+控血+淬体"）。每步只引入 1–2 个新概念。
- **首次天象事件**：用温和事件示范"因果链"与"应对策略"。
- **避免一次性信息墙**：复杂界面（丹炉/功法）首次出现用半透明引导层指向关键元素，可关闭。
- **可回查**：功法面板内置"修仙札记"，回顾已学机制。

## 10. 反馈与"Juice"（关键时刻的视听冲击）

呼应 `13-asset-art-audio.md`：

| 事件 | 视觉 | 音频 | 镜头/动效 |
|------|------|------|-----------|
| 种植/收获 | 粒子(土/灵光) | 柔和音效 | 轻微弹性 |
| 炼丹将成 | 炉光收敛、平衡条入安全区 | 升调 | — |
| **炸炉** | 橙红爆闪(限频)+烟尘+碎片粒子 | 爆鸣+耳鸣 | 强震屏、短暂失焦 |
| 雷预警→落雷 | 警示圈→白闪(限频)+电弧粒子 | 雷鸣(低频→炸裂) | 镜头微震/重雷强震 |
| **淬体收益甜区** | 角色金光描边、修为条暴涨 | 昂扬音效 | 慢镜头瞬切(可选) |
| **突破成功** | 经脉亮起、阶段过场 | 破立之音 | 全屏白闪过渡 |
| **飞升(通关)** | 紫雷劫池→白日飞升演出 | 史诗收束 | 长镜头升空 |

**原则**：juice 服务情绪曲线——日常克制、危机爆裂、高光庄严。所有强闪遵守 §8 限频。
