# 22 · 灵韵叙录：第一人称沉浸叙事模式（设计定稿）

> 「灵韵叙录」是 AeonVale 的第二模式：第一人称深度沉浸叙事。屏幕前的你即主角本人；离线精修的「境象图集」按你的道心走向分层选图合成，程序化 BGM/SFX 承沉浸主轴，心魔/师尊式 DM 旁白驱动选择。沿用主模式世界观骨架，叙事层、视角、结局体系独立。少数正典护栏在本模式内有意识修订（见 §13），**不回写修改 `02-narrative-bible.md` / `03-world-and-lore.md` 正典**。

---

## 0. 一句话定位

读同一份世界观，用第一人称 + 元叙事（打破第四面墙）重述「凡骨叩天」。你即那个被判废物的穿越者；每一次选择同时改写修仙结局与「你（玩家）与主角」的关系。终局明确区分三种意志：此界天道、屏幕外的控制者、以及一路承受伤与债后形成的主角自我。

## 1. 与主模式（第三人称生活模拟）的关系

- **共享**：世界观、角色基底（忘言叟 / 萧无极 / 逆 / 游方散修 / 采药女 / 阵匠老陆）、美术与音频管线、资产 manifest。
- **独立**：视角（第一人称 POV，主角不露脸）、叙事层（元叙事 / 第四面墙）、状态机（narration 层独立纯函数，不读不写 `src/sim/`）、结局体系（8 结局，独立于正典 4 主结局）。
- **位阶**：与 `00-DESIGN-BRIEF.md` 宪法冲突时宪法优先；与 `02/03` 的差异是平行模式的有意改写，不视为冲突。

## 2. 入口与元叙事首尾闭环

灵韵叙录的元叙事只在头尾各发生一次：开头是**开发者 → 玩家**的自白，结尾是**角色 → 玩家**的质问 / 驱逐。开发者自贬、MuseFlow 产品私货与颜文字只存在于 `intro.letter` / `intro.followup`；界面不解释其特殊身份，正式序章开始后完全让位给人物与处境。

### 2.1 标题屏入口

位置：`[data-app-surface="title"]` 内，`#flow-title-settings` 下方新增 `#flow-title-narration`（id 与 `AppScreen='narration'` 一致，显示文案「灵韵叙录」）。样式沿用标题屏按钮基底，前缀 `✦`（区别于常规项的 `▶`），下方副标题「以灵韵写就，再叙一遍。」暗示这是另一条路。

### 2.2 开发者自白（点击入口后浮现）

定位：开发者先以不完美的创作者身份向玩家说话，再把叙事权交给主角。视觉用暖色信笺（非 CG），顶部署名「— 来自开发者」，无角色立绘；界面不出现解释性标签，技术复用 `src/app/narrationVN.ts` 打字机引擎换皮并隐藏主玩法 Quick Menu。

文案（打字机逐段）：

1. 先容我说一句不太体面的实话：这是我第一次尝试做这样的游戏。回头看，它并没有抵达我最初想象的地方——那些笨拙和缺憾，我其实都看得见。
2. 可我一直舍不得把这个故事留在半途。它的山川、人物与命数，是我在做另一个项目时，一笔一笔长出来的。那个项目叫 **MuseFlow · 灵韵**，是一款为长篇小说作者准备的 AI 协作创作工具；你刚刚点开的「灵韵叙录」，名字也借自那里。
3. 既然已经借了名字，我索性坦白夹一次私货：如果你愿意，去看看灵韵，也欢迎回来告诉我哪里做得好、哪里依然笨拙。我会很认真地听 `(｡•̀ᴗ-)✧`
4. 至于眼前这款游戏——它或许还不够好，但这套设定，以及住在其中的人，我仍想好好讲给你听。于是有了这个模式：少一些隔岸旁观，多一点亲自走过。
5. 这一次，屏幕前的你，就是故事里的那个人。泥水、旧伤，还有每一次不能轻易收回的选择，都会从你的眼睛里发生。完整走到终局，大约需要一个安静的时辰。
6. 如果你愿意，就替他睁开眼吧。

### 2.3 双选项

- A「那就试一试吧 `(ﾉ>ω<)ﾉ`」→ 切到 `AppScreen='narration'`
- B「今天还是算了 `(｡•́︿•̀｡)`」→ 挽留一次后尊重退出

### 2.4 选 B 挽留（只一次，不纠缠）

选项区替换为：`唔，真的不看看吗…… (╥﹏╥) 好吧，我不拦你。「灵韵叙录」会一直留在这里；哪天想听了，再回来也不迟。` 随后收起对话框、回标题屏，入口保留可再点。第二次点入口给「已读跳过」。

### 2.5 E7 改写标题屏（元层第四面墙）

触发 E7（觉醒·合道驱逐）后，不直接黑屏，而是回标题屏，「灵韵叙录」入口被改写：变暗 + 角色立绘隔着屏幕凝视玩家（瞳孔可随鼠标）+ 入口文字变成「你确定还要再来一次吗？」。第四面墙从剧情延续到界面层。

## 3. 世界观与身份

- **永恒山谷**：边境谷地（地区）；**荒村**：谷中的村落，主角种地处。
- **太一宗**：修仙宗门，主角去测灵根处。
- **主角**：现代普通上班族穿越者（**异乡人**）。姓名 / 性别 / 肖像可由玩家自定义。外在寡言，内心以现代经验拆解陌生世界；幽默只来自处境与性格，不靠网络梗或模板化穿越桥段堆砌。醒来时对“外力解释”的短暂期待会迅速落空，随后必须依靠观察、实物和他人的行动理解此界。随功法推进，现代记忆逐渐模糊，终将面对「飞升的人是否还是原来的自己」。

## 4. 关键设定

### 4.1 神农（融合版，模式内正典）

一位（不强调「第一位」）百万年前的异世穿越者（空灵根）。最落魄时被一户凡人农家收留 → 下田报恩 → 发现灵草排列 / 土壤 / 灵气回流的规律 → **运用数理化构析此界本质、洞察天劫根源** → 成为「主动引劫」这一支的开创者。自愿匿名、无面，**生死永不揭晓**。其理论用**原世界文字（现代文字）写成规范化的论文，形式上又是一卷功法**——《偷天换劫诀》即此物；靠亲手种田能加深理解。

### 4.2 储物戒

- **打开方式**：打斗波动 + 主人「逆」神魂俱灭（化劫灰）→ 戒成无主 → 凡人可开。（主角此时还不知空灵根真相，故不能以空灵根开戒；逻辑自洽。）
- **遗物**：异种种子 / 残缺丹谱 / 破炉 / 残卷《偷天换劫诀》（神农的现代文字论文式功法）/ 玉佩（刻「逆」）/ **原世界文字的日记与夹层便笺**。
- **笔迹分层**：残卷正文属于神农；页边校验、日记与后六劫伤记属于逆；「勿独扛」由实体便笺补全。二人从不跨越百万年直接对话，逆神魂俱灭后也不以残影、传音或残魂继续发言。

### 4.3 空灵根揭示（模式内修订：功法 + 日记揭示，不写屈辱戏）

得遗物后，主角翻《偷天换劫诀》→ 震惊：竟是**自己原世界的文字** → 对照正文、页边批注与日记的不同笔迹 → 得知：逆是异乡人空灵根者、曾走通此路；神农是更早的异乡人先驱 → **「能读这文字」+ 功法对无灵根的描述 = 主角亦为异乡人 / 空灵根者的铁证** → 空灵根真相在此揭示。

- **不写「经历真正的无灵根屈辱」的戏**（修订正典护栏）。
- 测灵柱仍判无灵根（世界规则），主角仍被遣返，但不渲染屈辱。
- 忘言叟 / 萧无极的「道破空灵根」节拍移除：忘言叟改为「递锄头 + 农事比喻给神农线索 / 印证」；萧无极纯作「主题对手 / 顺天道的压迫者」。

### 4.4 接引长老（灵韵叙录原创，区别于主模式）

太一宗测灵判无灵根后，**接引长老因主角赴宗途中的义举（或测灵前考验中展现的坚持）认可其「恒心 + 正义感」** → 可惜摇头、给盘缠、「这不是凡人该待的地方」。

- 这是本模式相对主模式的差异化设定（主模式无此情节）。
- **角色本心锚 = 接引长老认可的「恒心 + 正义感」**。`defiance`（反抗觉醒度）的涨法 = 凡玩家替主角做出**违背此本心**的选择。

### 4.5 《偷天换劫诀》口诀（正典原文，直接用）

> 此诀非人所修。无灵根者，方可习之。以劫为薪，以骨为柴。偷天一线，换劫三生。习此诀者，已死。

## 5. 架构：narration 层独立状态机（不读不写 `src/sim/`）

灵韵叙录是 narration 层的**独立状态机**，结局判定（5 类型 + E6/E7）在 `src/app/firstPersonView.ts` 用**纯函数重新实现**。「复用代码层 5 结局」指复用**结局类型与叙事包装**（飞升 / 丹毒 / 渡劫身死 / 走火 / 寿终），**不是读 sim 实例**。sim 红线零风险。

状态变量（全部 narration 层派生管理，不进 `src/sim/`）：

- `cultProgress`：体修进度（阶段 0-7）→ 飞升判定
- `pillPoison`：丹毒 → 丹毒亡
- `madness`：走火值 → 走火入魔
- `lifespan`：寿元倒计时 → 寿终
- `tribGrip`：渡劫把握（布防 + 淬体 + 丹药派生）→ 渡劫身死 vs 飞升
- `defiance`：反抗觉醒度（0-100，门槛 ≈ 60）→ E6/E7 触发
- `bond`：红尘羁绊总量（阈值 ≈ 50）→ E6 vs E7 走向
- `shennongLore`：神农碎片收集度 → 揭示完整度（不影响结局分支）
- `meta`：章节进度 / 结局解锁（走 localStorage 或 `serialize.ts` 独立 meta 段，不进 sim 确定性核心）

## 6. 四幕主线骨架（逻辑闭环版）

```text
序章·幻灭期
 [黑屏·睁眼] → [永恒山谷] 先以声音、饥饿和炊烟确认处境
   ├→ 深处：迷路四日、误食毒菇 → 【E0 林中第四日】
   └→ 炊烟：进入荒村
 [荒村] 对外力解释的期待逐一落空；帮助村民与向忘言叟问路均为一次性行动
 [赴宗山道]
   ├→ 停步相助 → 木哨 → 善意沿山路传开
   └→ 绕行赶路 → 独自抵达，不再出现义举名声与木哨
 [太一宗] 测灵柱判无灵根；接引长老只认可亲眼所见的恒心，给盘缠遣返
 [回荒村] 忘言叟递锄头；“先看水往哪里走”成为功法与终劫的最早方法锚

第一幕·转折期
 [两修士斗法波及] 农庄毁 → 逆神魂俱灭、化为劫灰，遗言只剩“勿……”
 [储物戒] 打斗余波扫过无主戒 → 凡人可开；死者不会以残影回来解释
 [功法揭示] 神农正文先给出“察漏—引路—借势—淬骨”完整方法；
   逆的批注与日记以另一笔迹校验代价，三者共同证明主角的异乡人/空灵根身份
   ├→ 埋藏归隐 → 凡人蒙太奇(种田/老去/现代记忆彻底模糊,几十年一闪)→【寿终·落叶异乡】
   └→ 习诀("习此诀者,已死") → 决心走上偷天换劫之路 ← 第一幕收束

第二幕·淬劫期
 [线性淬劫主脊] 察漏 → 引路 → 采药女求救 → 借势 → 炼丹 → 村落半日 → 淬骨
   → 劫前赴约 → 守我 → 荒年粮仓 → 归一；不再返回任务菜单清 storylet

   人物事件嵌在两劫之间，让伤势、季节与关系连续发生；第六重完成前不能直达终局
 [心志抉择] 违背恒心与正义感 → defiance；真实维护关系 → bond；重大选择先用
   2–4 段独有后果兑现，再在宗门、回访、终劫以条件行回响
 [失败态] 丹毒、未成之骨接剑、强拆六劫秩序、荒年离村等各自收束到明确结局

终局·破立期
 [神农洞府] 以浮雕、试验台、正文与逆的抄本逐项闭合六条证据；
   不把未亲历线索伪装成玩家经历，且只保留神农生死这一处留白

   defiance<门槛 → 主角承认选择已构成自己，亲口答天道 → 【飞升】
```

闭环验收公式：`旧矛盾 → 有限准备 → 递进抉择 → 明确代价 → 带伤汇流 → 身体/关系/世界回收`。重大选择至少有即时回应与后续回响；汇流只能合并路线，不能抹掉玩家已经付出的代价。

## 7. 结局判定（分层）

## 8. 神农传说揭示节奏

- **过程**：六线索（见 §8.1）散落在闲谈 / 物件 / 遗迹 / 土地描述，玩家可提前自拼；正文不假定玩家已经看过未选择的支线。
- **终局前·闭合节点**（神农洞府）：**以新的实体证据场景化补完**——浮雕、编号试验台、正文与逆的抄本把缺失部分补齐，而非旁白宣称玩家“早已知道”。收集度影响提前认出的层次，不改变证据本身。
- **唯一留白**：神农最终**生死**（死于紫雷 or 已飞升）**永不揭晓**。

### 8.1 神农六线索（正典原文，分散方案）

1. 老农说这片地不知为何就是肥；从前有个人来过，虫子没了，稻子多了。
2. 荒草中立着一尊无面石像，基座被千万只凡人的手抚摸得光滑。
3. 残卷措辞不像传统功法，一些段落更像分析报告或工程记录。
4. 灵田的灵气分布和回流异常规整，不可能天然形成。
5. 深层土地里能翻出已经绝迹的古老灵虫虫壳化石。
6. 村志记载大饥之年有异人居于田侧，数年后虫患绝、稻米倍熟；村民不知姓名，只能刻无面像纪念。

## 9. NPC 阵容

- **忘言叟**：递锄头、农事比喻给神农线索 / 印证（原隐世修士，「看出异常 / 暗示空灵根」已移除）。
- **萧无极**：太一宗天灵根剑修，主题对手（非纯恶人），顺天道的压迫者；可触发「被萧无极诛杀」失败态。（「道破空灵根」已移除。）
- **「逆」**：另一位异世穿越者 / 空灵根者 / 《偷天换劫诀》修习者，高阶天劫力竭 + 被萧无极重创化为劫灰；主角的失败镜像。玉佩刻「逆」，遗言只剩「勿……」；后文仅通过其批注、日记与实体便笺补全「勿独扛」，绝不复活为残影代言。
- **游方散修 / 采药女 / 阵匠老陆**：正典 NPC，本模式复用为修仙同道。
- **收留主角的农家**：模式新增，bond 起点与情感锚；镜像「神农百万年前被凡人农家收留」。凡人会老死，bond 靠其后代 / 村民传承 / 守护意延续为「红尘羁绊总量」。
- **心魔（内心内阁）**：模式新增。参考 Disco Elysium 的多声内心，差异化音色（pitch / filter 调制，非 AI 配音），承载现代记忆侵蚀的具象化与「违心选择」的内心抗议。

## 10. 心志抉择节点（支线，涨 defiance）

`defiance` 涨法 = 玩家替主角做出**违背「恒心 + 正义感」本心**的选择。见义勇为只是其中一类。候选节点（随主线充实）：

- 散修欺凌凡人：出手（本心）/ 旁观（涨 defiance）
- 采药女 / 村民求救：救（本心，损）/ 弃（涨，降 bond）
- 利益诱惑（阵法坑人等）：拒（本心）/ 受（涨，降 bond）
- 揭露宗门 / 世道黑幕：揭（本心，险）/ 默（涨）

此类节点区别于主线修炼，是支线。

## 11. 叙录界面（章节流程图 + 结局图鉴）

参考 Detroit chapter flowchart + 视觉小说结局墙。「叙录」既是模式名的呼应，也是回顾界面的功能名。

- **顶栏**：章节进度 `已过 X/4 幕`，章节横轨（已过亮、当前脉动、未到暗）。
- **主区**：当前章节节点分支线——已走节点亮（场景名 + CG 缩略），未走节点 = `？` + 下方一行节点名线索（如「？·林深处」「？·宗门后山」）。
- **侧栏**：结局图鉴墙 `已解锁 X/8`，未解锁 = 问号图 + 线索文字（见 §7）。
- **入口**：标题屏「灵韵叙录」旁加「叙录」按钮，或 narration screen 内菜单项。

## 12. 落点与红线

- **入口按钮**：`index.html` 标题屏 + `src/app/appFlowMachine.ts` 的 `APP_FLOW_FOCUS_TARGETS.titleNarration` 与事件 `start-narration`（`title → narration`）。
- **对话框**：title 屏 modal overlay（不切 screen），复用 `src/app/storyVN.ts` 打字机换元叙事皮。
- **narration 层**：`src/app/narrationScenes.ts`（章节 / 场景 / 节点表，复用 `Scene{cgAssetId,lines,choices,converge}` 结构）+ `src/app/firstPersonView.ts`（纯函数：状态变量 → 选图 / 结局判定）。
- **BGM**：`src/app/main.ts` 渲染帧循环单点 `audio.setMusicContext({zone:'narration', tension: 跟走火值 / 临场走})`。
- **图集**：`cg.first-person.*` 挂进 `assets/manifest.json` 的 `sprites` 桶；`license:"AI-Generated"` + `ai_disclosed:true` + `human_edits:true`，开发期 `tools/` 离线生成 + 人工精修 + `tools/review-ai-art.py` 过审。
- **E7 改写标题屏**：title surface 在 E7 flag 下切换变体 DOM。
- **红线全守**：narration 层只读不写 sim、选图 / 判定用纯函数不引第二随机源、AI 生成只在 `tools/` 离线、`ai_disclosed` 透明披露、设计资料不进公开树。

## 13. 护栏：守的 vs 模式内修订的

**守（沿用正典）**：

- 神农自愿匿名无面，**生死永不揭晓**。
- 神农只是「主动引劫」这一支的开创者，非全体体修之祖。
- 神农真相过程中由玩家自拼，旁白不喂。
- 正式体质名称只能是「空灵根」，「漏斗 / 漏勺」仅作比喻。
- 主角的田 = 神农百万年前的田。
- 结局不分简单好坏，每个必须完成主题。

**模式内修订（仅本模式生效，不回写正典）**：

- 空灵根在《偷天换劫诀》功法 + 日记内揭示（**不经历无灵根屈辱戏**）。
- 神农理论写成原世界文字的规范化论文（又是功法）。
- 新增「接引长老认可恒心 + 正义感」情节（主模式无）。
- 结局体系 = 5 类型 + E6/E7，独立于正典 4 主结局。
- 储物戒以「打斗波动 + 主人神魂俱灭」打开（非空灵根吞吐）。
- 终局前给出完整神农传说（仅神农生死留白）。

## 14. 开放项

- `defiance / bond` 当前阈值固定为 60 / 50；后续若调参，必须通过 balance sweep 与八结局可达性门禁。
- meta-progression 当前采用 narration 专用 localStorage 分层表；若迁移到 `serialize.ts`，仍须保持与 sim 确定性核心隔离。
- 新增心志 storylet 时，必须同时设计即时回应、至少一次后续回响与终局可回收准备，不能只加数值。
- 「胜者修士」萧无极之外的次要反派 / 灰色 NPC（按需扩充）。
- 第一人称「境象图集」的分层库清单（背景层 / 道心氛围层 / NPC 立绘层 / 渡劫层）与各层图量。
- dev-only 实时生成对比开关的接入位置（与 `generativeMusic` dev-only 隔离同范式）。
