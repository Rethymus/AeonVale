# 30 · LLM 试玩代理首轮报告（judge 模式）

> 执行方式：按 `.claude/skills/llm-playtester` **judge 模式**——LLM 直接读取回放轨迹
> 并按 docs/17 §10 代理维度评分。素材：`tests/replay/fixtures/cultivation/
> cultivation-run-lifecycle.replay.json`（65 步完整一世：三轮议程 → 事件×2 →
> 参悟×2 → 首劫 22 步含 1 次 undo → perfect 突破 → 二劫 22 步 → timeout 身死 →
> 劫灰换代），辅以本代理此前 15 轮对主模式全流程的 20+ 次脚本化实走观察。
> **诚实声明**：非 bot 模式自对弈（API 配额所限）、非真人数据；"代理推断"均标注。

## 一、四个重点问题（授权四问）

### a) 首劫体验
- **轨迹证据**：首劫 22 步内含 1 次 undo 纠错后达成 perfect——撤步机制真实可用，
  甜蜜区在"预演-纠错"路径上可达；事件选择（watch-thunder-plot）真实注入了
  劫兆标签（previewLevelBonus=2、源威力+5、起始灵草），事件→劫备的因果成立。
- **代理推断**：预见 0 的首劫仍是最陡的理解坡。本轮已上两层缓解——界面的
  承雷三途指引（§8.18）+ 数值版基础预见（首劫结算后 floor 1，本日提交）；
  轨迹中二劫的 22 步漫游是**脚本固定输入的刻意设计**（timeout 路径覆盖），
  不能作为"玩家迷茫"的证据，需真人验证。

### b) 六格日程决策感
- **轨迹证据**：三轮议程各自结算，参悟预算"每议程 1 次"被严格遵守（3 议程
  2 解锁，未超支）；两次事件选择均走天象支，其标签全程流入首劫准备。
- **代理推断**：议程→事件→参悟→劫备是一条**真实闭合的因果链**（数据可证），
  决策感成立；但"重复同一活动的收益递减"在轨迹 facts 中不可见——玩家是否
  **感知到**递减需真人确认。

### c) 劫灰传承
- **轨迹证据**：epitaph → legacy-candidates → heir（stage 重置 0）链路完整；
  新增的 `tribulationsSettled` 换代归零意味着**继承人首劫重新盲**（有意设计：
  保留"劫兆需参悟"循环，与继承的知识节点互补）。
- **代理推断**：失败→学习的闭环在数据层闭合；情感落点（碑记文案/遗物选择
  界面）此前实拍品质良好，但"死亡瞬间的挫败→立碑的动机衔接"需真人验证。

### d) 节奏
- **轨迹证据**：三议程闸门后才首劫（备劫蓄力 → 一次释放），张弛结构存在。
- **代理推断**：开场 5 拍 + 入世 + 劫兆 ≈ 9 次点击进入首个决策屏，节奏可接受；
  二劫紧接一劫突破（无议程间隔）是本轨迹的脚本安排，正式流程中有"再备一轮"
  选项，节奏由玩家自控。

## 二、judge 四维评分（代理主观，0-5）

| 维度 | 分 | 依据 |
|---|---|---|
| 险胜感 | 4 | perfect 经 1 次 undo 达成——"差一点"与"恰好"的通道都在 |
| 决策多样性 | 3 | 两事件连续天象支（ordinal 碰撞，疑采样分布问题，见问题 2） |
| 节奏张弛 | 4 | 三闸门结构 + 引劫时机自控 |
| 挫败感控制 | 3 | 首劫盲的双层缓解刚落地，未经真人验证 |

## 三、最严重的三个问题

1. **首劫盲的验证缺口**（高）：两层缓解（指引文案+数值 floor）都以"假设有效"
   上线——需要真人 A/B 感受确认指引是否真被阅读、floor 1 是否足够。
2. **事件采样连续同型**（中）：轨迹两事件均落天象支。先查
   `sampleCultivationEvent` 的 ordinal→事件桶分布（可能只是 harness 序数
   碰撞），若分布偏斜再修。
3. **步数压力可读性**（中）：timeout 死亡路径存在，但轨迹中看不到"剩 N 步"
   的紧张度提示是否被注意——HUD 有余步显示，真人试玩时确认中后段（15+/22 步）
   是否读到。

## 四、真人试玩观察清单（15-30 分钟）

1. 首劫：不看攻略能否说出三种承雷结果？指引文案是否被读到？
2. 首劫失败后立碑时：是否理解"继承人首劫也会盲"？（数值版语义）
3. 六格日程：第 2-3 轮是否主动避免重复排同项？（递减可感知性）
4. 雷阵中段（步数过半）：是否注意到余步？会因此改变策略吗？
5. 新手感：按钮按压/浮层入场/推石震动是否"有物理感而无打扰"？（docs/29 批次）
6. 一世完整走完后：能否一句话说出"下一世我会怎么改"？（学习闭环成立性）

- bot 模式自对弈因 API 配额未执行（配额恢复后可跑
  `.claude/skills/llm-playtester/llm-playtest-bot.ts`——注意其当前动作词表
  面向旧世界 farm 动作，主模式 bot 需先扩词表，属退役阶段 2 的工具重定向项）；
- 本报告所有评分应与首轮真人试玩对照校准（技能"何时不用"条款）。

## 七、三项观测结论（代理+机制验证，2026-09-14）

### 观测 1：零苦练首劫 → 过载身死

代理 sweep（cultivation:metrics，seeds=8×4 策略）实测：零体魄训练
（balanced/herbalist）首劫 **100% 过载身死**。E2E 有机路径（真实 UI 全
点击）确认劫抉屏引导完整呈现。**结论：教学门成立**。

### 观测 2：ascetic 型首劫死率 25%

代理 sweep：ascetic 首劫死率 8/32=25%（stage-0 过载），与预期吻合。
苦练×3 路径首劫 0% 死亡。**结论：25% 教学关恰于"可感知但不致命"带内**。

### 观测 3：「先锻体」引导触达

劫抉屏在 stage 0 + 体魄 0 时**必现**引导（"此身体魄仍是 0……先以苦练把
体魄抬起来"），E2E 全点击有机路径已验证。非零体魄时正确隐藏。
