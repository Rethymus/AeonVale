# 28 · 《中国式家长》设计与玩家体验对标：可迁移结构与 AeonVale 落地

> **用途**：为 `27-cultivation-schedule-container.md` 的主模式产品化提供外部证据，不作为复刻规格。
> **研究快照**：2026-07-22。商店、评论与攻略会继续变化；具体数字只代表本次快照。
> **版权边界**：只迁移生命周期节拍、桌面信息架构、反馈闭环与代际回扣等抽象原则，不复制具体文案、事件、美术、角色、题材或小游戏形式。

---

## 0. 研究问题与证据边界

本轮不是问“怎样把 AeonVale 做成修仙版《中国式家长》”，而是回答四个更窄的问题：

1. 为什么它的日程养成在桌面端容易理解？
2. 为什么普通家庭题材能够支撑从出生到成人的长线代入？
3. 玩家在多周目、随机性、结局与代际系统上反复抱怨什么？
4. 哪些结构能原创迁移到“凡骨修行—天劫—劫灰传承”，并形成逻辑与生态双闭环？

证据分为三层：

- **官方事实**：Steam 商店说明与官方截图。
- **玩家事实**：高赞/长篇 Steam 评论、评论 API 快照和长期攻略记录。
- **媒体分析**：机核长评等编辑内容。

评论是玩家体验证据，不等同于官方规则；攻略可能受版本影响。下文会明确区分“观察事实”与“设计推断”。

## 2. 已交叉核验的设计事实

### 2.1 生命周期先于日程表

《中国式家长》的身份锚不是“拥有一个日程系统”，而是“普通家庭中的一个孩子”。姓名、年龄和教育阶段把每个回合放进可理解的人生时间轴：婴幼儿、幼儿园、小学、初中、高中、高考与成人结局。

固定节点持续改变背景、人物形象、可用活动、学习目标和关系内容。日程因此不是无穷刷数值，而是在“这一阶段即将结束”的压力下安排有限行动。

### 2.2 桌面版是一屏工作台，不是放宽的手机长页

官方 1920×1080 截图与全流程记录显示，其主要界面倾向在同一视口并置：

- 顶部资源与阶段信息。
- 左侧人物/属性或当前状态。
- 中央主场景、安排区或小游戏。
- 右侧学习目标、事项清单或解释区。
- 底部/边缘保留常用入口与确认动作。

安排、商店、关系与结果更多以覆盖层或整屏节点出现，玩家在比较选项时仍能看到上下文。主要操作不要求不断滚到页面底部。

### 2.3 核心链路把“获得能力”与“安排时间”分开

可概括为：

```text
行动力探索 / 获得属性与悟性
        ↓
解锁学习与娱乐事项
        ↓
安排有限日程
        ↓
结算属性、压力、满意度与特长
        ↓
考试、父母期望、关系、面子与人生节点评价
```

这使玩家在安排前先知道“我有哪些可能”，安排后再看到“我选择了怎样的人生”。

### 2.4 代际主题比永久加点更重要

官方定位把目标放在多代实现。高赞评论进一步说明，代际系统最有力的体验并非数值变强，而是玩家在理解培养规则后，行为逐渐像自己曾经反感的家长。换代由此形成一次主题反照。

## 3. 玩家评论反复暴露的断裂

### 3.1 叙事、状态与人物反应没有持续联动

多个长评指出：成绩、压力、爱好和长期行为与父母/NPC反应之间常缺少动态变化；某些事件文本虽然强烈，却不产生可持续的系统后果。

**推断**：短事件数量多不等于叙事闭环。事件必须写回状态，状态必须改变后续场景与人物反应。

### 3.2 代际只继承数值时，世界会失忆

玩家反复批评：上一代即使成为高收入职业、取得特殊人生或建立伴侣关系，下一代仍可能回到相同经济处境、相同对白与相同家庭模板。

**推断**：继承若不改变环境、关系、资源来源和价值观，只会缩短下一轮刷数值时间，不能形成新的故事。

### 3.3 多周目疲劳来自“重复但不改变”，不只是点击次数

玩家通常在前几代仍有探索兴趣；掌握机制后，重复小游戏、固定路线与相似对白迅速暴露。缺少世界记忆使重复操作无法产生新的意义。

**推断**：减少点击是必要条件，但更重要的是让同一活动在不同债务、生态和传承状态下产生不同后果。

### 3.4 随机性缺少来源、预告和改判

恋爱选项、面子特长、彩票或结婚等结果被批评为难以解释；长期准备可能被一次不可见随机直接否定。

**推断**：随机事件应显示风险来源，并提供准备、缓冲、保底或事后改判。随机可以制造故事，不能抹掉策略。

### 3.5 结局若只评价结果，会否定玩家走过的过程

部分评论认为职业结局使用固定价值判断，但日程中缺少与之对应的价值观状态；玩家难以理解“为什么我的选择得到这段评价”。

**推断**：结局必须列出因果证据，回收重要选择、关系、生态变化与失败代价。

## 4. AeonVale 的原创迁移

### 4.1 新游戏先完成四段立约，再开放日程

第一世开局使用四段“入世录”，每段完成一个必要问题：

1. **醒**：我是谁——记得异乡，却只有会老会伤的凡人身体。
2. **田**：我靠什么活——食物、灵草、苦练和炼丹必须有生态来处。
3. **灰**：世界为何需要我行动——仙人争斗首先摧毁凡人的田与生活。
4. **劫**：我为什么安排日课——以灵田放大吞吐、以丹药暂堵漏隙、以天劫把裂口炼成身体。

只有完成“身份 → 生计 → 危机 → 方法”的因果链，才进入新世身份、劫兆和六格日课。后继世不重复第一世世界说明，只显示前人留下的批注、遗物、债务与未竟之志。

### 4.2 桌面与移动端使用不同信息结构

#### 桌面（目标：≥1280×720）

```text
┌────────────────────────────────────────────────────────────┐
│ 一世日课 / 当前轮次 / 阶段说明                              │
├──────────────┬──────────────────────────┬──────────────────┤
│ 身份与状态   │ 六格竹简 + 六类活动       │ 下一劫与因果链   │
│ 余寿/心压    │ 资源先后与即时反馈        │ 操作与确认       │
└──────────────┴──────────────────────────┴──────────────────┘
```

- 页面本身不滚动；只有确实超量的局部面板允许内部滚动。
- 状态、选择、后果和主确认动作必须同时可见。
- 1280×720、1366×768、1920×1080 都是明确验收视口。

#### 移动端

- 退化为阶段化单栏：状态 → 日程 → 活动 → 因果 → 确认。
- 保留 44px 触控目标与键盘/读屏语义。
- 移动端允许纵向滚动，但不能让桌面端继承同一长页结构。

### 4.3 逻辑闭环

```text
读取劫兆
  → 安排六格日课
  → 按顺序结算资源与压力
  → 事件写回状态
  → 残卷改变下一劫预见/工具
  → 决定继续准备或主动引劫
  → 天劫检验此前准备
  → 突破、补修、死亡或飞升
  → 结算说明哪些准备导致了结果
```

界面必须始终能回答：“我现在做什么”“为什么做”“它怎样改变下一劫”。

### 4.4 生态闭环

MVP 的生态不是装饰性自然景观，而是资源和风险的来处：

```text
灵田 → 食物 + 灵草
食物 → 苦练 / 恢复
灵草 → 炼丹
丹药 + 肉身 → 改变天劫容错与安全雷威
天劫 → 损失灵草、突破肉身或结束此世
谋生 → 灵石 → 参悟与情报
歇息 → 降心压 + 增凡心 → 恢复后续活动效率与保命能力
```

当前切片用资源、肉身、心压、凡心与劫盘完成最小生态闭环；未来若增加人物关系或村落状态，必须接入同一因果链，不能成为独立好感度栏。

### 4.5 继续旅程是精确恢复，不是兼容入口

- “开始游戏”创建新的一世并进入入世录。
- “继续旅程”只依据新主模式存档显示。
- 恢复内容包括当前阶段、入世录页、日程草稿、事件/参悟/天劫状态、代数与传承候选。
- 不再把旧农庄世界存档当作主入口；旧模块只作为代码对照与回退资产存在。

### 4.6 传承必须让下一世面对不同世界

当前切片已保留残卷、遗物、碑记、死因和前人批注。后续扩展优先级：

1. 继承被证明过的知识，而非无限叠加智力。
2. 继承土地/生态损伤与修复成果。
3. 继承未偿天道债、人物记忆和村落立场。
4. 让同一活动因继承状态改变收益、事件与文案。
5. 终局生成可回看的“此世档案 / 劫灰年表”，解释关键因果。

## 5. 明确不迁移的内容

- 不迁移家庭、亲子、面子、高考和教育竞争题材。
- 不复制脑洞地图、面子大战、作文、红包、选秀等具体小游戏或事件。
- 不复制具体角色、美术、布局皮肤、文案与数值。
- 不把“几代刷永久属性”当作传承主体。
- 不以堆事件数量代替状态联动。
- 不让纯随机结果否定可解释的长期准备。

## 6. 当前验收证据

| 目标 | 自动化证据 |
|---|---|
| 第一世先讲清故事再进日程 | 浏览器 smoke 逐页断言四段入世录标题 |
| 桌面不需滚到底部操作 | 1280×720 测量 `.rp-planning.scrollHeight <= clientHeight`，确认按钮位于首屏 |
| 继续旅程不进入旧模式 | reload 后从标题点击继续，断言恢复 `roguelite-proto`，旧 `world` 保持隐藏 |
| 继续恢复精确阶段 | 断言恢复到同一入世录页；日程第一格与 `已排 1/6` 草稿保持 |
| 日程顺序真实影响结果 | `灵田→炼丹` 成功、`炼丹→灵田` 因缺草失败；`谋生→参悟` 同理 |
| 压力不是装饰数值 | 高压时收益衰减，歇息后后续格恢复并提高凡心 |
| 日程真实改写天劫 | 天劫准备、护脉丹、过载死亡/保命、灵草损失与突破结算浏览器门禁 |
| 传承与终局闭环 | 寿尽/劫死进入碑记并开启下一世；第六境进入飞升终局而非第七境日课 |

本文件的结论若与 `27` 冲突，以更晚的明确用户裁定为准，并同步修订两份文档，避免“调研建议”和“当前实现”分叉。
