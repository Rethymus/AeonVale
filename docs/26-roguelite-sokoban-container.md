## 1. 一句话 + 那一招鲜扭转

> **在灵田格上推/滑「五行阵石」,把雷劫这道"光"折射进自己的身体来淬炼它(以劫炼体),别让它烧到灵草。**

**扭转 = 一个反转**:几乎所有解谜都是"避开危险、把东西推到安全目标";这里反过来——**你要把危险(雷)故意导进自己身体**。这个"自找雷劈"的反转就是《偷天换劫诀》的味道,长在 Sokoban 这个人人会推的底上,零学习成本。可视化的"雷光光束"(类 Lazors / God of Light 的折射光路)让路径一眼看清,直击"看不懂"。

---

## 2. 核心循环(纯回合,无实时)

```
备劫(解谜) —— 给定雷源+身体+灵草+可推阵石,推/滑阵石搭出雷光路径「雷源→身体」
   │
引劫(commit) —— 雷光沿路径流:到身体=淬体(涨修为);途中穿灵草=烧毁(失资源)
   │
突破 —— 修为到阈→进下一阶(更大棋盘 / 多雷源 / 更紧约束)
   │
死亡 —— 失败→「逆灰烬」传承(meta,docs/25 §4 保留)
```

**全程回合制、可思考、零实时压力** —— 这是"看不懂"问题的直接解。

## 4. 可重玩性(直击 Sokoban 的弱点)

Sokoban 默认是手工关卡(有限)。本项目三招补救:
1. **每场天劫 = 种子化生成的棋盘**(确定性,可复现 / 可蒙特卡洛调参)。
2. **meta 传承**(死亡解锁新阵石类型 / 五行连锁 / 体修阶 —— docs/25 §4 硬传承直接复用)。
3. **递进约束**:更大棋盘、多雷源、大限步数预算、混合五行。

> **关键风险**:棋盘生成器质量决定可重玩性。原型 R4′ 先用「手工模板 + 种子扰动」(保证可解),全自动程序生成留后续阶段。

## 7. 风险与开放项(原型前定的默认)

- **棋盘生成器**(关键风险):默认「手工模板 + 种子扰动」。
- **推-only(Sokoban)vs 自由滑(华容道)**:默认 **推-only**(经典约束、谜题感最强)。
- **雷光单路径 vs 洪泛**:默认 **单可见路径**(最易看懂;洪泛留扩展)。
- **大限 = 步数预算**:默认 **开**(加张力 + 防无限试错)。
