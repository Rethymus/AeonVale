# 16 · 经济循环（Economy Loop）

> 本文件定义《Aeon Vale》的**资源流、稀缺模型、汇源平衡、库存压力与死亡经济**。
> 经济是 C5（凡人挣扎感）的主战场：玩家始终在稀缺中做取舍，而非在富足中做加法。
> 所有数值锚定 `14-game-balance-and-math.md` §11【平衡参数注册表】，内容节点取自 `15-content-tables.md`。

---

## 1. 经济总目标

| 目标 | 量化代理指标（对接 `17-testing-and-automation.md`） |
|------|---------------------------------------------------|
| 凡人恒弱 | 第 30 日玩家"灵石等价财富" ≤ 设计上限；无滚雪球 farm |
| 闭环自洽 | 任何阶段，产出-消耗回路不产生无限增值漏洞 |
| 稀缺驱动决策 | 玩家日均"被迫二选一"次数 ≥ 3（种植 vs 炼丹 vs 布阵） |
| 死亡有代价但不死锁 | 死亡后资源损失 30–60%，但保留知识类进度（残卷/已解锁丹方） |
| 通关可控 | 平均通关 18–25 h；95 分位 ≤ 35 h |

> **对数曲线而非指数**（参考星露谷经验）：早期产出快速爬升建立正反馈，中后期明显放缓——避免"后期金币如纸"或"后期一招通吃"。这是与 `14` §8 进度曲线配合的经济面。

### 2.1 关键节点标注

| 节点 | 类型 | 说明 |

| 灵气再生 | 源 | `regenBase`(P001) × 灵脉；**有限源**，不可无限取 |

| 灵石 | 硬货币 | 唯一可交易物，但交易极少（见 §5） |

## 3. 稀缺模型（Scarcity Model）

C5 要求四重稀缺叠加，制造"凡人挣扎感"。

### 3.1 种子稀缺

- **初始**：序章仅 `herb.mossling×3 + herb.dewroot×2`；第一幕储物戒开出的种子也仅够试种。
- **补充渠道**（全部有限/有风险）：
  - 舔包（魔修过境/古修遗冢）—— 战利品表含低概率种子
  - 散仙交易（`event.wandering-immortal`）—— 概率极低，且要拿战利品换
  - 事件（`event.demon-seed-rain` / `event.vein-surfacing`）—— 机会窗短
  - **收获反种**：成熟灵草有 `seedDropChance`（默认 0.5）掉 1 颗种子——**只能维持，不能扩张**（P-参数 `seedDropChance`，建议入注册表扩项）。
- **设计意图**：种子是"种群上限"。玩家无法一次种满全图，必须选哪几块地种什么——**田地即战略配置**。

### 3.2 灵气稀缺

- 见 `14` §2：灵气是流动公共池，多种多吸、越种越贫。
- 灵脉地块（`veinMultiplier=6.0`，P003）极稀缺（全图 ≤ 2–3 块），是兵家必争。
- **防止无脑堆灵石碎气**：`item.spirit-stone` 碎气回 `Q+=5`，但灵石本身稀缺（见 §5），且地块逸散（P004）让堆气效率递减。

### 3.3 丹药稀缺

- 每颗丹药 = 多日种植 + 炼丹 + 炸炉风险。
- 丹药**不可堆叠服用**（服一颗增 `load`，逼近暴毙），强制精打细算。
- 高 tier 丹方需高 tier 灵草（生长数百日）——时间是天然闸。

### 3.4 HP 稀缺

- maxHP 缓涨（100→200，`14` §8），但雷伤陡涨（12→50）——**相对越来越脆**。
- 回 HP 途径有限：`pill.bone-basic`（+30，要炼）、休息（慢、且灾年减效）、`item.mortal-rice`（凡间充饥线，回 HP 极少）。
- **HP 是最稀缺的"货币"**：每次天劫的控血（`14` §6.2）就是在花 HP 买修为。

## 4. 储物戒容量与库存压力

| 阶段 | 格数 | 扩容条件 |
|------|------|----------|
| 序章 | 无 | — |
| 第一幕（初始戒） | 16 | — |
| stage2 | 20 | `spirit-stone×10 + vein-shard×1` |
| stage3 | 24 | `spirit-stone×30 + vein-shard×2` |
| stage4 | 28 | `spirit-stone×60 + vein-shard×3` |
| stage5 | 32 | `spirit-stone×100 + vein-shard×5`（终局前最后一次） |

**压力来源**：
- 工具/设备/阵件**不堆叠**（占整格）：锄、镰、桶、炉、蒲团、伞……很快占满。
- 材料 `stack` 有限（`15` §5）：劫灰 30、灵石 50、残卷 8。
- **设计意图**：逼玩家做"今天带什么出门、留什么在家"的取舍——出门带错=白跑一趟，回家取=耗时间。这是慢节奏下的隐性张力。

**容量作为经济阀**：扩容是中期最大的灵石/碎片 sink，防止灵石通胀（见 §6）。

## 5. 货币与交易（最小化）

**设计立场**：凡人孤村，**无常规商店**。理由：C5 要求稀缺，一旦开放商店，玩家可 farm 灵草换钱再买丹，闭环打开即失衡。游戏的核心"交易"是**与天道的赌**（接雷换修为），不是市场。

### 5.1 唯一交易途径：游方散仙（事件触发）

| 项 | 设计 |
|----|------|
| 触发 | `event.wandering-immortal`（stage≥2，baseWeight=4） |
| 主动召唤 | 使用 `item.signal-flare`（stage2 制造，消耗品） |
| 交易物 | 灵石 `item.spirit-stone` 为唯一媒介 |
| 卖出 | 战利品（破损法宝/劫灰/妖兽内丹）→ 灵石 |
| 买入 | 稀有种子/残卷/解毒符/炉/灵脉碎片（**随机库存**，非全量） |
| 价格模型 | 固定价表 + 散仙"心情"随机折扣 ±20%（种子化，可复现） |

### 5.2 最小价格表（节选）

| 物品 | 买价(灵石) | 卖价(灵石) |
|------|-----------|-----------|
| Frostmarrow 种子 | 8 | — |
| Metalpine 种子 | 15 | — |
| recipe-fragment（随机） | 12 | — |
| anti-poison-charm | 5 | — |
| spirit-vein-shard | 40 | — |
| broken-talisman | — | 6 |
| tribulation-ash(×10) | — | 3 |
| beast-core | — | 4 |

> **通胀控制**：散仙库存随机且有限（每次 3–5 件），买空即无；价格随玩家 stage 微涨（+10%/stage），防止低阶 farm 高阶套利。这是"最小可行经济"——存在但不主导。

## 6. 通胀 / 通缩控制（平衡阀）

### 6.1 防滚雪球（防无损 farm）

| 风险 | 阀 | 机制 |
|------|----|------|
| 灵草无限种 → 无限丹 | 灵气耗竭 + 季节毁作 | `14` §2 负反馈；换季温/热草毁 |
| 灵石碎气无限堆 | 灵石稀缺 + 逸散 | 灵石主要靠舔包/散仙，量小；P004 逸散 |
| 阵法无损抗雷 | 阵法耐久 | 每抗一雷消耗，雷越多耗越快 |
| 控血无限刷修为 | 倒计时 + 雷数固定 | 天劫雷数固定（`14` §8），不能"多接几雷" |
| 重复 farm 低阶 | 高阶需求陡升 | `temperingEff` 下降 + `X_cap` 陡升，低阶修为不够用 |

### 6.2 防必死死锁

| 风险 | 阀 | 机制 |
|------|----|------|
| 丹药用尽 + 无材料 | 凡间作物保底 | `item.mortal-rice` 维持 HP 不饿死；休息慢回 |
| 种子断种 | 收获反种 0.5 + 事件补给 | 永不真正归零，但永远紧张 |
| 突破失败归零 | 险胜留 70% 修为 | `14` §8.3"可挽回的局部失败" |
| 走火入魔绝境 | 重生给 `herb.dao-root` 1 颗 | 设计的"最后一口气"——黑色幽默 + 不死锁 |

### 6.3 产出-消耗平衡表（每 stage 日均，设计目标）

| stage | 日均灵草产出 | 日均丹药产出 | 日均丹药消耗 | 净丹药库存趋势 |
|-------|-------------|-------------|-------------|----------------|
| 1 | 1.5 | 0.3 | 0.2 | +0.1（缓慢积累） |
| 2 | 1.2 | 0.25 | 0.3 | -0.05（开始紧张） |
| 3 | 1.0 | 0.2 | 0.35 | -0.15（必须精算） |
| 4 | 0.8 | 0.15 | 0.4 | -0.25（依赖战利品补充） |
| 5 | 0.6 | 0.1 | 0.5 | -0.4（终局消耗战） |

> **意图**：净库存趋势从正转负，玩家越后期越"吃老本"——这是"凡人挣扎感"的经济表达。模拟应验证此趋势（见 §8）。

## 7. 死亡 / 损失经济

> **已对齐（`20` D-03 = 混合制 C）**：roguelite vs 存档的开放问题已由 `20` D-03 裁定。下方为**采用模型 + 理由**。

### 7.1 采用方案：混合制 C（不回档 + 阶段性流动资产损失）

| 死亡类型 | 损失 | 保留 |
|----------|------|------|
| 丹毒暴毙 / 被雷劈死 / 饿死 | **当前 stage 修为 X 折损 50%**（不回档、不归零）；身上未装备的丹药/材料 **丢失 50%**；储物戒战利品掉落现场（可回尸点取回 50%） | 已解锁的**丹方/残卷/阶段**（知识进度）；已建的**阵法地基**（不含消耗性阵件）；灵草**种植中**的不毁 |
| 走火入魔 | 修为折损 50%；maxHP 临时 -10（需休息恢复）；给 `herb.dao-root×1` | 同上 |
| 突破"险胜" | 修为折损 30% | 全部 |

**理由**：
- **不采纳纯 roguelite 重开**：本游戏单局 18–25 h，纯重开惩罚过重，劝退；且"凡人挣扎"已由数值稀缺充分传达，不需额外 permadeath。
- **不采纳纯存档 scum**：会让死亡无意义，破坏 Pillar 1（脆弱）。故**死亡时强制损失"流动资产"**（修为/丹药/材料），但保留"知识资产"（残卷/阶段）。
- **关键**：知识保留 = 玩家下次能更聪明地种/炼/布阵——**学习曲线不归零**，符合 C5"可挽回的局部失败"。

### 7.2 死亡经济汇

死亡本身是**最大单次汇**：折损 50% 修为 + 半数流动资产。它一次性泄掉通胀压力，让游戏不滚雪球。这是设计上的"泄压阀"。

## 8. 经济自动化测试钩子（对接 `17-testing-and-automation.md`）

无头模拟必须监控以下经济指标，作为平衡调参的目标函数输入：

| 指标 ID | 指标 | 采集方式 | 健康区间 | 异常处置 |
|---------|------|----------|----------|----------|
| E001 | 第 30 日玩家灵石等价财富 | 模拟快照 | ≤ 40 | > 40 → 通胀，降产出或升 sink |
| E002 | 第 1 次天劫前丹药库存 | 模拟快照 | 2–5 颗 | < 2 → 产出过低；> 5 → 过松 |
| E003 | 日均"被迫二选一"次数 | 行为日志 | ≥ 3 | < 3 → 资源过丰 |
| E004 | 净丹药库存趋势斜率 | 每 stage 回归 | stage3 后 ≤ 0 | > 0 → 滚雪球风险 |
| E005 | 死亡后回归相同 stage 用时 | 模拟 | 1–3 h | > 3 h → 损失过重；< 1 h → 损失过轻 |
| E006 | 灵脉地块占用率 | 模拟 | 100%（永远被争） | < 80% → 灵脉不够稀缺 |
| E007 | 储物戒满载频率 | 模拟 | 中后期 ≥ 40% 时间 | 过低 → 容量压力不足 |
| E008 | 散仙交易触发后"买入率" | 模拟 | 60–80% | 过低 → 库存不吸引；过高 → 玩家依赖交易 |
| E009 | 炸炉率（玩家主动） | 模拟 | 5–15% | 过低 → 玩家太保守；过高 → 炸炉阈过严 |
| E010 | 通关时剩余丹药 | 模拟 | 1–3 颗 | 过多 → 终局过松；0 → 终局过紧 |

> 这些指标是 `17` §4 蒙特卡洛调参的**目标代理**。E002/E004/E010 尤其关键——它们直接反映 C5 是否成立。
