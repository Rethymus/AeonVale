## 0. 缘起与诊断(摘要)

主模式同时在当四种游戏——星露谷级生活模拟 / 深度涌现模拟 / 叙事游戏 / 求职作品集 demo——四者直接冲突,而"作品集 demo"才是真约束。星露谷的深度来自 Eric Barone 四年全职堆出的**内容体量**,这是单人在作品集周期内不可能复制的护城河,故得到一个"星露谷形状的空骨架",读起来像"粗糙修仙版种田游戏"(`21 §6.5` 自标风险)。**根因不是"种田太重",是容器与内容不匹配。**

世界观/故事(空灵根 / 偷天换劫诀 / 神农 / 逆 / 蝼蚁叩天)是**强且稀缺的好资产**,问题在倒进了错误容器。

| ✅ 该学的锚(小体量+可重玩+单人可完成) | ❌ 别再追的锚(看似相关,实为 scope 陷阱) |
|---|---|
| Dome Keeper(2人,双相循环) | 星露谷(内容量=护城河,4年全职) |
| Loop Hero(玩家自造威胁=难度旋钮) | 鬼谷八荒(官方自承内容超计划200%,23GB/百万字) |
| Slay the Spire(intents 预告+组合深度) | 太吾绘卷(8年开发,作者承认 scope 失控) |
| 觅长生(五行规则引擎=深度来源,4人3.5年) | Core Keeper(永不结束沙盘) |
| Brotato(30分钟硬封顶) | Dave the Diver(Nexon出资30人,非独立可复制样本) |

## 1. 新定位

> **主模式 = 第三人称「雷劫炼体」roguelite:在一块灵田上布阵备劫 → 天道预告下一劈 → 半实时承雷淬体、控血求生 → 死则掉境界、保知识残卷传承。故事做 meta 脊梁,与灵韵叙录(读故事)正交。**

- **与灵韵叙录的关系**:共享世界观,形态正交。灵韵=第一人称 VN 把故事**讲**给你(读故事);主模式=第三人称让你**活**在世界里、靠多周目拼出真相(玩世界)。两者不重复。
- **服务 `D-32`**(先作品集 MVP):本转向的全部目的是把主模式做成一个可完工、可交付、能 demonstrate 产品判断的成品。

## 2. 核心循环(双相)

**单一核心动词 = 引劫。** 一切只为"备劫"或"渡劫"服务。

| 相 | 节奏 | 玩家做什么 | 复用系统 |
|---|---|---|---|
| **A 备劫**(慢/治愈/计时) | 水墨留白 | 在**单块战术灵田**排布五行灵草(引雷/绝缘/导湿)、炼备劫丹、读《偷天换劫诀》推六阶 | `08` 种田(塌缩为战术田)+ `06` 炼丹(简化为消耗品)+ `09` 残卷 |
| **预告点**(转折) | — | 天道以**劫云/天象显形"下一劈的属性/数量/落点"** | 新增(StS intents),最该加的一刀 |
| **B 渡劫**(快/肾上腺素) | 紫电劫云 | **半实时**控血"扛 N 雷不死"换淬体;布的阵决定雷往哪走 | `05` 天劫(Phase B 心脏)+ 阵法 + `D-06` 擦弹 |

**张力公式**:慢节奏积累安全感 → 大限/寿元与预告制造焦虑 → 半实时渡劫制造肾上腺素 → 突破制造多巴胺 → 回到慢节奏(但更强,也更被天道记账)。

## 3. Phase B · 半实时动作渡劫(已定:半实时)

半实时 = **实时走位/反应 + 预告风息 + 波次呼吸**,非纯 twitch,非纯回合。服务"慢/快张力"的"快",并把长期悬空的 **`D-06` 擦弹 PerfectBlock** 接入为技能天花板。

### 3.1 动作动词集(刻意只留 4 个 —— Cult of the Lamb 原则: mash 的每一边都要比单类型游戏更简单)

1. **走位 (Move)**:实时在灵田格上移动身体。决定站在哪道劈雷的落点。
2. **承劫 (Take the bolt)**:核心风险/回报——主动站在劈雷落点"吃雷"换淬体修为;躲则保命但少收益。即 02/05 的"控血扛 N 雷不死"。
3. **擦弹·完美承劫 (PerfectBlock, `D-06`)**:劈雷命中瞬间的精准输入,减伤 + 提升淬体品质(quality bonus,沿用 `05` ExposureCoeff/QualityBonus)。高玩天花板。
4. **服丹 (Pop pill)**:反应式使用承雷丹/生骨丹控血;Phase A 备的有限数量,稀缺即张力。

### 3.2 擦弹 PerfectBlock 接入(`D-06` 终于有家)

`D-06` 长期"未接入"。本转向给它明确归宿:Phase B 的技能天花板与"险而可破"曲线的体现。完美承劫的雷给更高淬体品质(`qualityBonus`,引 `05 §4.2`/`14`)。这是把存量资产变成核心手感的直接收益。

### 3.3 "半实时"的体现

- **劈雷风息 (windup)**:每道雷有"劫云锁定 → 落雷"的显形预告,玩家有反应窗但有限(类 bullet-hell telegraph)。预告内容来自 Phase A 末的天道显形。
- **凝神微时停**:开丹药菜单/评估局势时短暂减速或暂停,保留战术层,不沦为纯反射。
- **波次结构**:雷以波次落下,波间有微呼吸(重走位、服丹、看下一波预告),非连续倾泻。

### 3.4 体修身份(`D-26` / `D-28`)

主角是无灵根凡人转没落体修。Phase B **不射火球、不施法**;全靠身体(承/躲/抗)+ 阵法控场(Phase A 预设的战场)。可选的守田兽 courier(`D-28`/`D-40`)作 Phase B 辅助,**推迟到 R4-d 之后**。身体即工具,强化主题。

### 3.5 手感来源

走位解谜 + 时机(PerfectBlock)+ 资源(丹/血)+ 风险回报(吃雷换力)。4 动词,深度来自组合与时机,不靠内容量。

## 4. 死亡传承 · 硬档(已定:掉境界、保知识残卷)

lore 原生的 roguelite meta-progression。比"全保留"有 stakes,比"全失去"不劝退。

### 4.1 死失 / 死留

| 💀 死失(身体归零) | 📜 死留(残卷知识) |
|---|---|
| 当前境界 / body-foundation 进度(回到凡骨) | 已「悟」残卷阶(重爬更快/带加成) |
| 累积修为 / 淬体 buff | 已得丹方 / 阵图(可重炼重布) |
| 身上丹药 / 材料 | lore 碎片(神农/逆,永久叙事解锁) |
| | 小幅永久传承 buff(Hades mirror 式,慢积累以抗天道升级) |

### 4.2 再攀登加速循环(roguelite 核心成瘾环)

知识在 → 重爬各阶更快 → 推得更远 → 死 → 再爬。每次死亡后,玩家因"已悟"而能更高效地回到此前高度再突破。**这正是 roguelite 的核心钩子,且 lore 原生。**

### 4.3 lore 框定

每次死亡,主角灰烬入「逆」之列;下一修士(玩家)承残卷知识。**身体死,路径知识活。** 即 `02 §2.5`:"前一个的灰烬,铺成后一个的台阶。" 主角是这条死路上最新的一环。

### 4.4 与大限 / 寿元(`D-29`)

每 run = 一世寿命;体修突破延寿延长当世;终因渡劫或寿尽而死,残卷传承。**终局紫雷飞升 = 唯一"真胜"**:身体在紫雷中碎裂重塑为仙躯(`02 §1.4`),不再归零。这给了"飞升"真正的重量。

## 5. 可重玩 / 扩展性来源(深度来自组合,非内容量)

1. **五行相生相克 + 布田空间解谜**(觅长生 / Backpack Hero):灵草"种在哪"= 你的 build;小规则集 → 组合爆炸,零新美术。
2. **天道升级 = 玩家自造威胁**(Loop Hero):你越偷天,预告越凶、劫云越密。**你的贪婪就是难度旋钮**——最强的一句话机制。
3. **预告 = 种子化劈雷时刻表提前可知** → 备劫是确定性解谜,非 RNG 惩罚(StS intents 哲学)。
4. **meta 传承树**:长期成长线;新灵草/新阵/新残卷阶 = 可无限扩展的内容接口,每条都是小增量。

## 6. 叙事集成

### 6.1 六阶残卷 = 周目目标线

`22 §6` 的六重淬体(察漏 → 引路 → 借势 → 淬骨 → 守我 → 归一)直接做成 roguelite 的周目目标/meta 进度脊梁。每阶通关揭一段神农/逆 lore。

### 6.2 可移植设定清单(从灵韵 / 原典搬进主模式,修掉现在生硬感)

1. **砍网络梗式穿越桥段 + 屈辱戏**——灵韵 `§13` 已删,主模式 `02 §2.1` 还留"延迟到账/老爷爷"套路,廉价;改搬灵韵克制(幽默只来自处境)。
2. **"偷天换劫诀 = 现代文字写成的规范化论文(又是功法)"**——最不撞车的钩子,做成可读解谜核心(残卷=可读"分析报告")。
3. **接引长老(认可恒心+正义感)**——给主角尊严锚和"逆天"之外的人物动机。
4. **天道预告制**——渡劫前天象显形"下一劈"。
5. **死亡 = 逆灰烬传承**(见 §4)。

### 6.3 与灵韵区分

灵韵=第一人称 VN,叙事优先,~1–2h 线性分支(读故事);主模式=第三人称,系统优先,roguelite 多周目 + meta 传承(玩世界)。共享世界观,形态正交。

### 6.4 ⏳ Notion 原典抽取清单(执行阶段,web_reader 配额 8/3 恢复后或走 Notion API 分页)

执行 R4-c 时需从 Notion《永恒山谷:大道之歌》设定集 / 小说章节抽取:① 残卷六阶原文措辞;② 逆 / 神农具体情节与可复用对白;③ 接引长老场景细节。**先定方向再按需取用**,避免照搬导致突兀。

## 7. UI/UX · 操作手感 · 像素氛围

- **一屏一棋盘**:灵田始终可见(直击 portfolio 视觉首印风险——常驻层必须有人格)。**砍掉多场景 / 跨场景寻路 / NPC 日程**(`21 §4.2` 最大未完成债)。

## 10. 分期迁移 R4(沿用 R1/R1.5/R2/R3 范式)

- **R4-a 核心循环原型**(go/no-go 闸):sim 上一块田、一个备劫相、一次预告劈雷、半实时存活/死亡。**先证明好玩**。不通过则回设计台。
- **R4-b meta 传承层**:死亡掉境界/保残卷,逆灰烬框定;独立于 sim 核心。
- **R4-c 故事接入**:六阶 + 神农/逆 lore 滴灌 + §6.2 可移植设定 + Notion 抽取。
- **R4-d 美术/手感**:双相视觉语言、预告 UI、像素承诺、PerfectBlock 手感调校。
- **R4-e 垂直切片**:一次完整飞升可从头打到尾,作品集可交付。

**明确推迟**:多场景、社交、后终局生活层、背包大重构、天象沙盘、守田兽 Phase B 辅助。

**每阶段必须过门禁**:`pnpm governance:check`、`pnpm typecheck`、`pnpm test`、`pnpm build`。
